# ChargerPrices

Community-sourced EV charger prices for Australia. Users report what a charger
costs, and everyone sees the latest price and how fresh it is.

- Data model: [docs/data-model.md](docs/data-model.md)
- Database schema: [supabase/migrations](supabase/migrations)

Planned stack: Next.js (TypeScript) on Vercel, with Supabase for Postgres,
auth and file storage.
